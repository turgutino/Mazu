# Mazu — Promo Video Script (32-47 sec)

Goal: showcase what Mazu actually does — persistent project memory, checkpoint/rollback and branching, and the option to run on a local model with no cloud bill — plus an open-source contributor call-to-action. Every claim in the voiceover should be something the README can back up; do not add superlatives or comparisons to other products. Minimal jargon, maximum visual impact.

---

## Scene 1 (0-6s) — The Problem

**Visual:** A minimalist AI chat interface, someone typing a long explanation of their project, then closing the window. A new window opens — completely empty, nothing remembered.

**Voiceover (EN):** "Your AI agent forgets everything the moment you close it. One wrong move, and there's no way back."

**Seedance2/Minimax prompt:**
```
A minimalist dark-themed chat interface on a laptop screen, a person typing a long
message, then closing the window. A new window opens, completely empty, cursor
blinking. Clean tech aesthetic, blue/purple accent lighting, subtle motion blur,
cinematic close-up on the screen.
```

---

## Scene 2 (6-14s) — Mazu Remembers

**Visual:** Terminal screen, `mazu chat` is typed, quickly "we use PostgreSQL" is entered. Cut — a different day, a new session, a question is asked: "what database do we use?" — the answer comes back instantly, correct.

**Voiceover:** "Mazu keeps a memory of your project. Decisions, conventions, mistakes — saved locally, and you can see and edit all of it."

**Seedance2/Minimax prompt:**
```
Terminal window with dark background, green/white monospace text typing rapidly,
showing a command line coding assistant conversation. Smooth transition (day-to-day
cut) to the same terminal, a question typed, an instant correct answer appears.
Tech/developer aesthetic, subtle glow on cursor, fast confident typing animation.
```

---

## Scene 3 (14-26s) — Rollback and Branching

Split into two beats: (3a) a mistake gets undone, then (3b) one point in time
splits into two parallel paths that get compared side by side.

### 3a — Rollback (6s)

**Visual:** Code files changing rapidly (autonomous work in progress), then an error appears (red error message). A "rewind" visual (clock hands spinning backward), the screen snaps back to a clean previous state.

**Voiceover:** "One mistake — one command undoes everything. Code, memory, conversation, all together."

**Seedance2/Minimax prompt:**
```
Code editor with files rapidly changing (autonomous coding animation), then a red
error message flashes. A stylized rewind/time-reversal visual effect (clock hands
spinning backward, screen ripple effect), the code snaps back to a clean previous
state. Cinematic, tech-noir lighting, blue-to-red-to-blue color shift.
```

### 3b — Branching (6s)

**Visual:** A single glowing checkpoint node on a timeline splits into two diverging branches (like a git graph, but alive and glowing), each branch runs its own code independently, then both branches slide side by side on screen for a visual "compare."

**Voiceover:** "Not sure which approach is better? Fork the same point in time, try both, and compare the results — side by side."

**Seedance2/Minimax prompt:**
```
A single glowing node on a dark timeline splits into two diverging branching paths
(git-graph style but animated and alive), each branch pulses with its own flowing
code particles, camera pulls back to reveal both branches sliding into a clean
side-by-side split-screen comparison view. Cyan and violet branch colors, sleek
data-visualization aesthetic, smooth motion.
```

---

## Scene 4 (26-34s) — Local Models

**Visual:** A Wi-Fi/cloud icon fades out with a strike-through, a "$0" symbol appears, the laptop keeps working locally with a local model.

**Voiceover:** "Point it at a model on your own machine, and there's no cloud account and no per-token bill. Prefer a cloud model? Mazu works with those too, with a spending limit you set."

**Seedance2/Minimax prompt:**
```
A cloud/wifi icon on screen fades out with a strike-through animation, replaced by
a "$0" glowing text and a laptop icon pulsing with local activity indicators (small
gears/chip icon). Minimal, clean, green accent color for "free/local" theme.
```

---

## Scene 5 (34-47s) — Closing + Call to Action

**Visual:** The Mazu ASCII-art logo assembles on screen, a GitHub star icon appears beside it. Text overlay fades in: "Fully open source. Looking for serious contributors."

**Voiceover:** "Mazu — a coding agent with a memory you can inspect and a history you can undo. Fully open source, and looking for contributors. Join us on GitHub."

**Seedance2/Minimax prompt:**
```
ASCII-art style logo "MAZU" assembling itself character by character on a dark
terminal background, glowing cyan/purple gradient, a GitHub star icon appears next
to it with a subtle sparkle animation. Text overlay fades in below the logo:
"Open Source. Contributors Wanted." Clean end card, subtle particle glow effect.
```

---

## Notes

- All scenes should share the same "dark terminal / cyberpunk-lite" aesthetic so cuts feel visually continuous.
- Voiceover in English, calm and confident tone — informative, not salesy.
- Music: minimal, low-tempo electronic (lo-fi tech), a brief tension chord at 3a (the rollback moment) that resolves into something more confident/expansive going into 3b (the branching reveal) works well.
- Scene 5's on-screen text ("Fully open source. Looking for serious contributors.") should stay legible for at least 3 seconds — viewers need time to read it, not just hear it.
